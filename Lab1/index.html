1. История создания

JavaScript был создан в 1995 году программистом Бренданом Айком (Brendan Eich), работавшим в компании Netscape. Изначально язык назывался Mocha, затем — LiveScript, и только потом получил современное имя JavaScript.

Интересно, что название «JavaScript» появилось в маркетинговых целях — чтобы привлечь внимание к языку Java, который тогда был очень популярен. Несмотря на схожесть названий, это совершенно разные языки.

В 1996 году язык был стандартизирован организацией ECMA и получил официальное название ECMAScript. С тех пор вышло множество версий: ES3 (1999), ES5 (2009), ES6 (2015) и последующие ежегодные обновления.

Сегодня JavaScript — один из самых популярных языков программирования в мире. Он используется как на стороне клиента (в браузере), так и на стороне сервера (благодаря среде Node.js).

2. Краткий обзор языка

JavaScript — это мультипарадигменный язык, поддерживающий функциональное, объектно-ориентированное и императивное программирование. Он динамически типизирован, то есть тип переменной определяется во время выполнения.

Основные характеристики

  1. Динамическая типизация
  2. Функции — объекты первого класса
  3. Прототипное наследование
  4. Асинхронность на основе событий
  5. Кроссплатформенность

Области применения

  • Веб-разработка (frontend)
  • Серверная разработка (Node.js)
  • Мобильные приложения (React Native)
  • Игры и мультимедиа

Популярные фреймворки

  • React
  • Vue
  • Angular
  • Svelte

3. Примеры кода

Простейший пример программы на JavaScript:

// Вывод приветствия в консоль
let name = "Мир";
console.log(`Привет, ${name}!`);

// Функция сложения двух чисел
function sum(a, b) {
    return a + b;
}

console.log(sum(2, 3)); // 5

Пример работы с массивом и стрелочной функцией:

const numbers = [1, 2, 3, 4, 5];

const squares = numbers.map(n => n * n);

console.log(squares); // [1, 4, 9, 16, 25]

Подробнее о языке можно узнать в документации MDN.
