1. История создания

Язык JavaScript был разработан Бренданом Эйхом в компании Netscape в 1995 году. Изначально язык назывался Mocha, затем был переименован в LiveScript, и только 4 декабря 1995 года получил своё современное название — JavaScript [citation:1].

Интересно, что название «JavaScript» было выбрано как маркетинговый ход, чтобы привлечь внимание к новому языку благодаря популярности Java в те годы. Однако, несмотря на схожесть названий, эти языки имеют совершенно разную архитектуру и назначение.

В 1996 году Microsoft выпустила свой интерпретатор JScript для браузера Internet Explorer, что привело к необходимости стандартизации языка. В 1997 году JavaScript был стандартизирован под названием ECMAScript в организации ECMA International [citation:11].

Ключевые этапы развития

  1. 1995 — создание языка Бренданом Эйхом в Netscape
  2. 1996 — выпуск JScript от Microsoft
  3. 1997 — стандартизация ECMAScript 1
  4. 2009 — выход ECMAScript 5 с новыми возможностями
  5. 2015 — релиз ECMAScript 6 (ES6) с классами и модулями

2. Краткий обзор языка

JavaScript — это высокоуровневый, интерпретируемый язык программирования, который обычно используется как встраиваемый язык для программного доступа к объектам приложений [citation:2].

Основные характеристики

  • Динамическая типизация
  • Слабая типизация
  • Автоматическое управление памятью
  • Прототипное программирование
  • Функции как объекты первого класса

Список с маркером-картинкой

  • Клиентская разработка
  • Серверная разработка (Node.js)
  • Мобильные приложения (React Native)

3. Примеры кода

Ниже представлены примеры кода на JavaScript с цветовой подсветкой синтаксиса.

Пример 1: Вывод сообщения

// Простая программа на JavaScript
let message = "Привет, мир!";
console.log(message);

Пример 2: Цикл for

// Вывод чисел от 0 до 9
for (var i = 0; i < 10; i++) {
    console.log(i);
}

Пример 3: Функция

// Функция для расчёта площади круга
function calculateArea(radius) {
    const area = Math.PI * Math.pow(radius, 2);
    return area;
}

const result = calculateArea(5);
console.log(`Площадь: ${result}`);
